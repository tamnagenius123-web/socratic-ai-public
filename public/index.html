Process

소크라테스 토론은 이렇게 진행됩니다

1

텍스트 선택

고전 명저 또는 직접 업로드한 텍스트로 토론 주제를 선택합니다.

2

소크라테스 토론

AI가 10턴 동안 주장 명료화 → 근거 → 추론 → 반례 → 수정 → 종합 단계로 압박합니다.

3

실시간 분석

논증 그래프, 레이더 차트, 인지 과정 점수를 실시간으로 추적합니다.

4

성장 기록

초기 주장과 수정된 주장, 사용한 근거, 남은 약점을 세션 기록에서 확인합니다.

Features

깊은 독서와 실전 문제 해결

독서 스파링

도서의 정확한 근거 조각에 기대어 주장을 만들고, 반례와 추가 질문을 통해 수정합니다.

시나리오 훈련

여러 분야의 라이브러리 근거를 고정한 뒤, 이해관계자와 제약이 있는 실제 문제에서 선택과 결과를 반복합니다.

나의 라이브러리

직접 올린 도서는 나의 계정에만 보이며, 저장·근거 분할·인덱싱 상태를 구분해 보여줍니다.

근거 출처

스파링과 시나리오에 사용된 도서, 문자 범위, 내용 해시를 스냅샷으로 남겨 재현성을 키웁니다.

거짓 성공 없는 상태

근거 부족, 생성 오류, 재시도 가능, 삭제 대기 상태를 성공처럼 포장하지 않고 원인과 다음 행동을 보여줍니다.

세션 기록

이전 주장, 턴별 대화, 근거 사용, 현재 상태를 계속 보존해 학습자가 변화 과정을 되짚을 수 있게 합니다.

Assessment

측정되는 비판적 사고 역량

논리적 구조화
